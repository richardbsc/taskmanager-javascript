
# Declaración de uso de Inteligencia Artificial

**Proyecto:** TaskManager
**Estudiante:** Richard Vaca
**Institución:** ECOTEC

## 1. Herramientas de IA utilizadas

Durante el desarrollo de TaskManager utilicé ChatGPT como herramienta de apoyo para consultar ejemplos de código JavaScript, revisar funciones y corregir problemas encontrados durante las pruebas.

También utilicé sus sugerencias como referencia para implementar algunas funcionalidades y organizar el código de la aplicación.

## 2. Prompts utilizados

Prompt 1:

"Revisa el código JavaScript de mi gestor de tareas y ayúdame a identificar por qué el botón para crear tareas no funciona correctamente. Indícame qué debo corregir."

Prompt 2:

"Revisa la función de almacenamiento local y ayúdame a comprobar que las tareas se guarden correctamente después de actualizar la página."

## 3. Errores y ajustes realizados

Durante las pruebas del proyecto se revisaron los siguientes aspectos:

- Funcionamiento del botón para crear y guardar tareas.
- Corrección del botón de actualización al editar una tarea.
- Validación de campos para evitar registros vacíos.
- Verificación de la persistencia mediante localStorage.
- Comprobación de los eventos de JavaScript utilizando la consola del navegador.

Se realizaron pruebas manuales para verificar las correcciones y comprobar el funcionamiento de las tareas.

## 4. Conclusión

ChatGPT se utilizó como apoyo técnico para consultar ejemplos, resolver dudas y revisar partes del código. Las funcionalidades se comprobaron mediante pruebas en el navegador y los cambios se registraron en GitHub.
